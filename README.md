# Shadows of Soldiers - Official Landing Page

A modern, cinematic landing page for the tactical military game "Shadows of Soldiers" built with React and Vite.

## 🎮 Features

- **Cinematic Hero Section** - Full-screen background art with prominent CTAs
- **Primary Actions** - Discord community invite and Steam wishlist buttons
- **Video Showcase** - Embedded gameplay trailers
- **Social Media Integration** - Links to YouTube, Patreon, and Facebook
- **Responsive Design** - Optimized for all devices
- **Modern Animations** - Smooth transitions and hover effects

## 🚀 Quick Start

### Prerequisites
- Node.js 16+ and npm

### Installation

```bash
# Navigate to project directory
cd ShadowsOfSoldiersStaticWebpage

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🎨 Design Guidelines

### Color Palette
- **Background:** Dark tones (#0a0a0a, #1a1a1a)
- **Discord Button:** #5865F2 (Discord Purple)
- **Steam Button:** #1b2838 (Steam Dark Blue)
- **Accent:** Gold/Military green based on game theme

### Typography
- **Headings:** Bold, military-style fonts
- **Body:** Clean, readable sans-serif

### Responsive Breakpoints
- Mobile: 320px - 767px
- Tablet: 768px - 1024px
- Desktop: 1025px+

## 📦 Dependencies

- **react** - UI library
- **react-dom** - React DOM rendering

## 🚢 Deployment

### GitHub Pages (FREE - Configured & Ready!)

This project is pre-configured for free GitHub Pages hosting.

**Quick Deploy:**
```bash
# Initialize git and commit
git init
git add .
git commit -m "Initial commit"

# Create repo on GitHub, then:
git remote add origin https://github.com/YOUR_USERNAME/ShadowsOfSoldiersStaticWebpage.git
git push -u origin main

# Manual deployment (alternative):
npm run deploy
```

**Result:** Your site will be live at:
`https://YOUR_USERNAME.github.io/ShadowsOfSoldiersStaticWebpage/`

📖 **Full instructions:** See [GITHUB_PAGES_DEPLOYMENT.md](./GITHUB_PAGES_DEPLOYMENT.md)

### Other Options
- **Netlify/Vercel:** Works too, but GitHub Pages is free and pre-configured!
